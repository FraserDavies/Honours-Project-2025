Core Data Entities

Projects Table

project_id (primary key)
project_name
project_description (optional)
start_date
end_date
created_at
updated_at


Tasks Table

task_id (primary key)
project_id (foreign key)
task_name
description (optional)
start_date
end_date/duration
progress_percentage (0-100)
is_milestone (boolean)
parent_task_id (self-referencing for subtasks/hierarchy, nullable)
display_order (for custom sorting)


Dependencies Table

dependency_id (primary key)
predecessor_task_id (foreign key to tasks)
successor_task_id (foreign key to tasks)
dependency_type (e.g., 'finish-to-start', 'start-to-start', etc.)
lag_time (optional - days/hours to wait after predecessor)


Resources Table (optional but recommended)

resource_id (primary key)
resource_name
resource_type
capacity (optional)


Task_Resources Table (for many-to-many relationship)

assignment_id (primary key)
task_id (foreign key)
resource_id (foreign key)
allocation_percentage (optional)
